# Дипломный проект: нейросетевая модель для подбора реабилитационного лечения

Учебный ML-проект 2023 года, выполненный в рамках дипломной работы по направлению «Фундаментальная информатика и информационные технологии».

Цель проекта - исследовать возможность классификации состояния пациента по набору лабораторных и общих признаков и на основе результата выбрать одну из заранее заданных схем реабилитации.

## Участие в проекте

В рамках дипломной работы я занималась подготовкой данных, адаптацией и доработкой кода под задачу, запуском обучения модели и анализом полученных результатов.

## Данные

Изначально планировалось использовать реальные обезличенные данные партнёрского университета, однако получить подходящий набор данных не удалось. Поэтому для учебного прототипа был сформирован синтетический датасет на основе доступных исходных материалов и структуры исследуемых показателей.

## Что реализовано в исходной версии

- загрузка данных из Excel;
- обработка пропущенных значений;
- преобразование категориального признака пола;
- масштабирование признаков;
- разделение данных на обучающую, валидационную и тестовую выборки;
- многоклассовая классификация с помощью `MLPClassifier` из scikit-learn;
- отслеживание accuracy на обучающей и валидационной выборках;
- построение матрицы ошибок;
- проверка модели на тестовой выборке;
- ввод набора признаков и получение результата классификации.

## Стек

Python, pandas, NumPy, scikit-learn, matplotlib, openpyxl, Jupyter Notebook / Google Colab.

## Структура репозитория

- `Diplom.ipynb` - файл Jupyter Notebook с кодом, графиками и результатами исходного эксперимента;
- `data.xlsx` - синтетический учебный датасет;
- `README.md` - описание проекта.

## Запуск

1. Откройте `Diplom.ipynb` в Google Colab или Jupyter Notebook.
2. Поместите `data.xlsx` в рабочую директорию.
3. Выполните ячейки последовательно сверху вниз.

## Ограничения исходной версии

Проект создавался как учебный прототип. В исходной реализации есть методологические ограничения: предобработка данных выполняется до разделения выборки, а датасет является синтетическим. Поэтому сохранённый показатель accuracy отражает только результат учебного эксперимента и не должен интерпретироваться как качество модели на реальных медицинских данных.

## Важно

Проект не является медицинской системой или инструментом для постановки диагноза. Результаты модели не предназначены для использования при принятии медицинских решений.
