# Дипломный проект: нейросетевая модель для подбора реабилитационного лечения

Учебный ML-проект 2023 года, выполненный в рамках дипломной работы по направлению «Фундаментальная информатика и информационные технологии».

Цель проекта — исследовать возможность классификации состояния пациента по набору лабораторных и общих признаков и на основе результата выбрать одну из заранее заданных схем реабилитации.

## Что есть в исходной реализации

- загрузка данных из Excel;
- обработка пропущенных значений;
- преобразование категориального признака пола;
- масштабирование признаков;
- разделение данных на обучающую, валидационную и тестовую выборки;
- многоклассовая классификация с помощью `MLPClassifier` из scikit-learn;
- отслеживание accuracy на обучающей и валидационной выборках;
- построение матрицы ошибок;
- проверка модели на тестовой выборке;
- ввод набора признаков и получение результата классификации.

## Стек

Python, pandas, NumPy, scikit-learn, matplotlib, openpyxl, Jupyter Notebook / Google Colab.

## Структура репозитория

- `Diplom.ipynb` — исходный ноутбук дипломного проекта;
- `data.xlsx` — набор данных, использованный в проекте;
- `README.md` — описание проекта.

## Запуск

1. Откройте `Diplom.ipynb` в Google Colab или Jupyter Notebook.
2. Поместите `data.xlsx` в рабочую директорию ноутбука.
3. Выполните ячейки последовательно сверху вниз.

## Ограничения исходной версии

Это учебный прототип, а не production-решение. В исходном ноутбуке есть методологические моменты, которые при современной переработке стоило бы исправить:

- imputer и scaler обучаются до разделения данных на train/validation/test, из-за чего возможна утечка информации;
- график, подписанный как Validation Loss, фактически не рассчитывает loss на валидационной выборке;
- качество модели стоит перепроверять после корректного разделения и предобработки данных.

Поэтому сохранённый в ноутбуке результат accuracy следует воспринимать только как результат исходного учебного эксперимента, а не как надёжную оценку качества модели.

## Важно

Проект создавался как учебный дипломный прототип и не является медицинской системой или инструментом для постановки диагноза. Результаты модели не предназначены для использования при принятии медицинских решений.
